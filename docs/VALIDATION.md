# 当前验证记录

版本：0.5.0。日期：2026-10-20（Asia/Taipei）。

## 已通过

- 自动测试 72/72：配置隔离、模型请求、HTTP 错误、桌面认证、配置失败恢复、角色 SQLite 登记、图片、主动联系、微信就绪与聊天节奏。
- chat-native-smoke：加载真实腾讯插件 2.4.10 与真实 OpenClaw；使用独立假账号、仅本机模拟微信和模型端点。两条连续消息完整进入同一次模型请求；temperature 正确传递；路由标签被移除；两条回复各发送一次。
- chat-ui-smoke：真实 Chrome 浏览器验证本地与 API 参数分别保存、切换后保留、聊天节奏设置保存、刷新后恢复；没有页面 JavaScript 错误。后台运行时操作使用隔离桩，不等同于真实云端测试。
- role-restart-smoke：真实 OpenClaw 与本机模拟 API，先产生会话，再连续四次保存人物、验证新设定和用户资料进入实际请求，更新记忆并重启。六次启动都记录为 clean_stop，没有触发异常重启保护；API temperature 也进入实际请求。
- 当前公开便携版 desktop-native-smoke：真实 Electron 窗口、Windows 系统加密保存、退出并重新打开后恢复密钥全部通过；采用独立配置和假服务地址，没有调用真实模型。

## 使用者仍需确认

- 手机微信真实连续发送、分条回复和取消的体感，取决于网络、插件和模型响应速度；模拟服务结果不能代替实际验收。
- 用户实际 DeepSeek / 中转 API 兼容性、计费与模型权限。验收不自动发送真实云端测试请求。
- Qwen3.5 9B 的延迟、内存和显存占用随量化与上下文变化；没有把其他模型的旧测试成绩当成本模型成绩。
- 提示词改善提问习惯属于生成行为，不能保证每次严格执行；需要结合多轮实际聊天调整。

本文件只记录当前版本，不继续堆叠旧版本验证历史。

- 窗口恢复回归：原生 Electron 窗口隐藏后，第二次启动会显示原窗口；同时复验系统加密密钥保存与重开恢复。
