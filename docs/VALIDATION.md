## 执行环境差异

Codex 沙箱中，OpenClaw 使用的 SQLite 原生 realpath 访问曾出现 EPERM。普通文件读取和 JavaScript realpath 正常，经工具隔离外执行审核后，真实 OpenClaw 角色调用通过。本次没有为绕过该问题修改用户系统或 OpenClaw 依赖代码。

Windows CIM 查询也受执行环境限制，因此停止逻辑改为监督进程持有确切 ChildProcess 句柄，并通过随机令牌的 loopback 控制接口停止，不依赖按 PID 盲杀。

## 功能边界

- 长期记忆由 CLI 明确增改查删；微信自然语言自动记忆尚未实现。
- 原始归档、日志、备份和微信历史不因 memory forget 自动抹除。
- 当前禁用通用主机工具、远程嵌入、联网搜索、主动问候，未实现实时微信语音通话。
- 模拟 API 成功不能代替真实服务商计费接口的验证；插件安装成功也不能代替本人扫码与收发。
- 电脑休眠、关机或断网会暂停微信陪聊。
